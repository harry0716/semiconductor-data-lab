# 半導體製程資料分析實驗平台

這是「半導體製程資料分析實驗平台」的可執行 MVP。系統以半導體製程資料作為情境，讓學生完成原始資料觀察、資料匯入、品質檢查、資料處理、視覺化、基礎分析與報告撰寫。

## 目前版本

版本：0.1.0 MVP

目前採本機前端工作台，優先驗證完整教學流程。系統可直接在瀏覽器操作，不需要雲端帳號或資料庫。

## 已完成

- 內建「設備製程參數與良率分析」資料集。
- 已建立三種案例資料，每種案例 3 份，共 9 份 CSV：
  - 案例 A：設備製程參數與良率分析。
  - 案例 B：批次製程漂移分析。
  - 案例 C：檢測品質與複合指標分析。
- 介面可直接切換案例資料集並下載目前選取的原始資料。
- Step 2 的下載功能由平台即時產生 CSV，不依賴本機檔案路徑或瀏覽器直接抓取資料集網址。
- CSV 載入與預覽。
- 欄位說明與原始資料觀察區。
- 資料品質檢查：缺值、重複列、非數值內容、類別命名不一致、日期格式混用、疑似異常值。
- 資料處理：設備名稱正規化、移除重複、移除或填補缺值、數值轉換、良率區間、溫度篩選、排序、還原、重置。
- 操作歷程與處理理由。
- 圖表：設備平均良率長條圖、溫度與良率散佈圖、良率直方圖。
- 分析：描述統計、設備群組比較、相關性分析、簡單線性迴歸。
- 分層提示與提示使用紀錄。
- 報告預覽、HTML 匯出、列印或另存 PDF。
- Node.js 本機伺服器與自我測試。

## 啟動方式

最簡單方式：雙擊 `start-platform.bat`。

或在此資料夾執行：

```powershell
npm start
```

開啟：

```text
http://127.0.0.1:4174/frontend/index.html
```

不建議直接雙擊 `frontend/index.html`，因為瀏覽器可能會限制本機模組與資料檔讀取。

## 目前限制

- 本機 MVP 支援 CSV。XLSX 匯入將在後端 FastAPI 匯入服務階段加入。
- 目前資料保存在瀏覽器狀態，重新整理後會回到示範資料。
- 教師帳號、學生帳號、PostgreSQL、S3 儲存與 Docker 部署保留在下一階段開發。
